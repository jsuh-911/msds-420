1. Install geldata/EdgeDB from the following URL:

https://docs.geldata.com/learn/installation



2. From the directory that has your IPYNB script and schema, execute the following commands (in the order specified)

gel project init
gel project info
gel instance list
gel instance status -I yelp_reviews
gel migration create
gel migrate
gel ui



3. Misc geldata/edgdb commands:

gel instance list
gel instance destroy --force -I yelp_reviews
gel server list-versions --installed-only



4. From Python venv/conda terminal, execute the following commands:

pip install uv
uv pip install -r requirements.txt
